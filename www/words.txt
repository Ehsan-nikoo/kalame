# فهرست کلمه‌های بازی «کلمه»
#
# هر خط یک کلمه است، به این شکل:
#     کلمه | معنی ساده
#
# - بازی مرحله‌های جدید را فقط از همین کلمه‌ها می‌سازد.
# - کلمه‌هایی که توی جدول نیستند ولی از حروف دایره ساخته می‌شوند، «کلمه‌ی جایزه» حساب می‌شوند.
# - معنی‌ها با زدن روی کلمه‌ی پیدا شده در جدول نشان داده می‌شوند.
# - برای حذف یک کلمه، خطش را پاک کنید. برای اضافه کردن، یک خط تازه بنویسید.
# - فقط کلمه‌ی ساده (بدون فاصله و نیم‌فاصله)، رایج و مناسب همه‌ی سنین.
# - خط‌هایی که با # شروع می‌شوند توضیح هستند و در بازی خوانده نمی‌شوند.
